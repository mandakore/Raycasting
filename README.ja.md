# 概要
 このプロジェクトは、『Wolfenstein 3D』にインスパイアされた、C言語による3Dグラフィックスエンジンです。レイキャスティング（Ray-casting）の原理を用いて、2Dのマップデータから動的な3Dの一人称視点表示を実現しています。<br>
 本プロジェクトでは、ソフトウェアレンダリング、パフォーマンスの最適化、そして厳格なメモリ管理といった、システムプログラミングおよびグラフィックスプログラミングの基礎に重点を置いています 。


# 使用した技術とアルゴリズム

- DDA（デジタル・ディファレンシャル・アナライザ）
3Dの壁をレンダリングするために、DDAアルゴリズムを実装しました。単純なステップごとの光線増分（計算負荷が高い）とは異なり、DDAはグリッドの交点までジャンプして判定を行うため、計算回数を大幅に削減できます。 <br>

また、「魚眼効果」を回避するために、カメラ平面に対する垂直距離を使用して壁の高さを計算しています： <br>
$$perpWallDist = (mapX - posX + (1 - stepX) / 2) / rayDirX$$

- ブレゼンハムの線分描画アルゴリズム
ミニマップやデバッグツールの描画には、ブレゼンハムのアルゴリズムを採用しました 。このアルゴリズムは、コストの高い浮動小数点演算を避け、整数演算のみで2点間に直線を引くことを可能にします。<br>
$$d = 2 \Delta y - \Delta x$$

# 実行方法

1. Linix環境のマシンにクローンしてください。<br>
   FHD(1920×1080)以上のモニターが推奨されます。
```bash
git clone https://github.com/mandakore/Raycasting.git
```
<br>

2. `make` を実行するとMinilibXが自動でクローンされ、ビルドが行われます。
```bash
cd Raycasting
make
```
<br>

3. マップファイルのパスを渡すことで起動します。
```bash
./game maps/valid/00_subject.cub
```
<br>

4.  `W` `A` `S` `D` でプレイヤーが移動、 `←`  `→` でプレイヤーの視点が回転します。

5. `Tab` キーでマウスポインタの有効/無効を切り替えることができます。
