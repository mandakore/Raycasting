# Description
cub3D is a graphics project from the 42 curriculum that introduces the basics of
raycasting, inspired by early 3D games such as Wolfenstein 3D.
The goal of the project is to create a simple 3D representation of a maze
using a 2D map, textures, and real-time rendering.

This project involves implementing a raycasting engine in C,
handling player movement and camera rotation,
rendering textured walls, and managing user input and events.
It also requires working with low-level graphics through [the MiniLibX library](https://github.com/42paris/minilibx-linux.git),
as well as applying mathematical concepts such as vectors and trigonometry.

Through this project, students gain a deeper understanding of
graphics programming, game loop architecture,
and performance considerations in a constrained environment.

# Instructions


1. clone this repository to your local machine.
```bash
git clone https://github.com/mandakore/Raycasting.git
```
or
```bash
git clone git@vogsphere ...intra...hoge...
```
<br>

2. Move to the project directory and run `make`.
```bash
cd Raycasting
make
```
<br>

3. Run the program with a specified map file.
```bash
./game maps/valid/00_subject.cub
```
<br>

4. You can move with `W` `A` `S` `D` and rotate the camera (change your view) with the `left` and `right` arrow keys.

5. Pressing `Tab` toggles the visibility of the mouse cursor.
